Лабораторная работа № 2 — вариант 4 «Музейный каталог искусства»

Состав проекта:
- ProgramForTextAnalysis2.py — код поисковой системы, базового поиска и экспериментов A/B/C/D;
- 04_Музей_искусства/ — исходные CSV и README выбранного варианта;
- search_results.csv — TOP-5 для всех 30 запросов (конфигурация C);
- experiment_metrics.csv — Hit@5 и MRR@5 на 8 открытых запросах;
- baseline_results.csv — результаты базового поиска по совпадению слов;
- analysis_errors.txt — два примера ошибок ранжирования.

Запуск из корня папки:
    python ProgramForTextAnalysis2.py

Зависимости:
    pip install pandas numpy scikit-learn nltk
    pip install pymorphy3   (рекомендуется для настоящей русской лемматизации)

Примечание о воспроизводимости:
В среде, где были подготовлены файлы, pymorphy3 отсутствовал, поэтому расчётные
CSV получены с резервной нормализацией NLTK SnowballStemmer. Скрипт автоматически
использует pymorphy3, когда он установлен, иначе — SnowballStemmer. При установке
pymorphy3 повторный запуск может дать немного отличающиеся оценки и ранги.

Правила эксперимента:
A — без лемматизации, без удаления стоп-слов, униграммы;
B — с лемматизацией/нормализацией, без удаления стоп-слов, униграммы;
C — с лемматизацией/нормализацией, удалением стоп-слов, униграммы;
D — с лемматизацией/нормализацией, удалением стоп-слов, униграммы и биграммы.
TF-IDF обучается только на документах: fit_transform(documents), затем transform(queries).
Метрики считаются исключительно по 8 парам из dev_relevance.csv.
